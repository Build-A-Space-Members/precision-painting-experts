# Precision Paint Experts — website

An SEO-first Node.js rebuild of [precisionpaintexperts.com](https://precisionpaintexperts.com). It keeps every original
URL and all of Precision Paint Experts' business details (logo mark, phone, service area, services), and uses the
layout and look of [spraytexpainting.com](https://spraytexpainting.com).

- **Static HTML for every page**, generated by `src/build.js` from JSON content in `content/pages/`. Pages work without
  JavaScript.
- **Express server** (`server.js`): clean URLs, legacy 301 redirects, security and caching headers, a real 404 page,
  and the estimate-form endpoint.
- **409 URLs**, matching the original sitemap:
  - 282 indexable pages
  - 127 tag and category archives, which are kept live but set to `noindex,follow`

See [REBUILD-REPORT.md](REBUILD-REPORT.md) for the full write-up.

## Commands

```bash
npm install
npm run build            # production build → dist/ (indexable)
npm run build:staging    # preview build: noindex meta + robots.txt Disallow
npm start                # serve dist/ on $PORT (default 3000)
npm run dev              # build + serve
npm test                 # build + SEO checks + content-uniqueness review
npm run images           # regenerate responsive images/favicons from assets/
npm run test:webmcp      # browser test of the AI-agent tools (server must be running; see script header)
```

## Environment variables

| Variable | Purpose |
|---|---|
| `PORT` | Port the server listens on. |
| `SITE_URL` | Canonical origin used in canonicals, sitemaps, and JSON-LD. Default: `https://precisionpaintexperts.com`. |
| `SITE_ENV=staging` | Build adds `noindex`, and the server adds `X-Robots-Tag: noindex`. Use this for previews. |
| `CANONICAL_HOST` | For example `precisionpaintexperts.com`. Redirects `www`, other hosts, and HTTP to `https://` on this host. |
| `FORM_WEBHOOK_URL` | **Required for the estimate form.** Each request is POSTed here as JSON (Zapier, Make, a CRM, or an email relay). If it is not set, the form tells visitors to call instead and does not pretend to send. |

## Editing content

Each page is one JSON file in `content/pages/`. The format is in `content/SCHEMA.md`. Business facts the copy may
state are in `content/FACTS.md`, and site-wide data (phone, hours, cities, services) is in `src/data/site.js`. After
editing, run `npm test`. It fails on broken links, duplicate titles or descriptions, missing canonicals, orphan pages,
and pages whose wording overlaps too much with other pages.
